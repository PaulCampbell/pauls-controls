auto-suggest

The autosuggest component provides a text input with suggestions dropdown. 

			
<auto-suggest
	items='[
		"Apple", 
		"Banana",
		"Cherry", 
		"Date", 
		"Elderberry", 
		"Fig", 
		"Grape", 
		"Honeydew"
	]'
></auto-suggest>

<script type="module">
	import './dist/auto-suggest.js';
	const autosuggest = document.querySelector('auto-suggest');
	autosuggest?.addEventListener('selectionchange', (event) => {
		console.log('Selection changed:', event.detail.selection);
	});
</script>

bounding-boxes

The component expects bounding boxes in YOLO format (centre X, centre Y, width, height) with all values normalised between 0 and 1.

The component optionally supports an autosuggest feature for labeling boxes. 

				
<bounding-boxes
	src="muppets.jpg"
	boxes='[
		{
			"xPosition": 0.6182206444474247,
			"yPosition": 0.4021144903858238,
			"width": 0.4422906048819742,
			"height": 0.6912467010179716,
			"label": "Pig"
		},
		{
			"xPosition": 0.10062365879828326,
			"yPosition": 0.5866061329646852,
			"width": 0.18412184817596566,
			"height": 0.3743684805831343,
			"label": "Chicken"
		}
	]'
	autosuggestItems='[
	  "Pig", 
	  "Chicken", 
	  "Frog", 
	  "Rabbit", 
	  "Totoise"
	]'
></bounding-boxes>

<script type="module">
	import './dist/bounding-boxes.js';

	const viewer = document.querySelector('bounding-boxes');
	viewer?.addEventListener('boxeschange', (event) => {
		console.log('Boxes updated:', event.detail.boxes);
	});
</script>

upload-input

The upload-input component provides an image upload interface with drag-and-drop support and a preview area. 

				

<form action="/upload" method="POST" enctype="multipart/form-data" id="uploadForm">
  <upload-input id="uploader"></upload-input>
  <button type="submit">Upload</button>
</form>

<script type="module">
	import './dist/upload-input.js';

	const form = document.getElementById('uploadForm');
	const uploader = document.querySelector('upload-input');
	uploader?.addEventListener('image-loaded', (event) => {
		console.log('Image loaded:', event.detail.file.name);
		console.log('Data URL:', event.detail.dataUrl);
	});

	form.addEventListener("formdata", (event) => {
		const file = uploader.getFile();
		if (file) {
			event.formData.append("image", file, file.name);
		}
	});
</script>
